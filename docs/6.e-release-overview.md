Please find below all the features that have been added to (what is now) the Raku Programming Language since language level release 6.d in 2018.

> Note that because of the lack of being able to properly handle different language levels in 2018, many of the described features became de-facto part of the 6.d releases since 2018.  It is the intent of the Raku Steering Council to keep the 6.e level *really* frozen during the development cycle for the 6.f language releass.

## 2018.12
- Enums can now have private methods mixed in
- Added `Endian` enum and implemented new methods in `blob8`/`buf8` for reading/writing native values
- Added `Kernel.endian` method
- Implemented `Blob.readint` / `Buf.writeint` methods (removed later)
- Added `.native-descriptor` for async sockets
- Added `.Real` method to native array

## 2019.03
- `$_` container is no longer `is dynamic`
- Added `buf8`/`blob8` read-(u)bits / write-(u)bits methods for reading/writing any number of **bits**
- Added `$?DISTRIBUTION` to give introspection and IO capabilities to the current `Distribution
- Made `QuantHashes` parameterizable to limit the type of value that can be put in them
- Allowed `is Type` trait to handle parameterization like `is Set[Int]`
- Added a `dynamic-scope` lexical pragma

## 2019.07
- Telemetry's `snap` now also accepts an optional "checkpoint" message
- Telemetry: allow snap `:heap` for heap snapshots
- `CompUnit::Repository::FileSystem` objects can now also be created from an `IO::Path`
- `EVAL` now supports a `:check` flag to just check syntax (like `raku -c`)
- Implemented support for `Kernel.free-memory` and `Kernel.total-memory`
- Added the `CachedIterator` role for creating iterators on cached lists

## 2019.11
- Pseudo-packages now return `Failure` for a missing symbol
- Grammar now returns Failure when failing to parse
- `LEXICAL::` pseudo-package includes all symbols visible in the lexical scope, including dynamic symbols from caller chain
- `SETTING::` pseudo-package includes all symbols from all available `CORE`s
- `UNIT::` pseudo-package includes all lexicals visible at unit level
- Symbol binding is now possible for all pseudo-packages
- Individual language-release `CORE`s are now accessible via `CORE::v6<rev>` namespaces- Added GB2312 and GB18030 encodings
- Added support for `.rakumod` extension

# 2020.01
- Smartmatching typed Arrays against same-typed Positionals now returns True (e.g. `Array[Str:D] ~~ Positional[Str:D]`), which returned False before
- Class attributes and methods are now prioritized over those from roles
- DateTime class now accepts picosecond precision
- `$*ARGFILES` special variable now defaults to `$*IN` if no arguments
- An attempt to use methods `index`, `indices`, `contains` on a `List` now gives a warning
- Add `Version` type coercer to `Str`
- Add `Supply.repeated/decode/encode/first/collate/head/comb/split/lines` methods
- Add new `is built` Attribute trait
- Add `$*RAKU` variable
- `Raku` is now allowed to be used as a language in EVAL
- Add `:$match` named parameter to `comb` subroutine when called on `Cool` object when the `$matcher` argument is a `Regex
- Add `log2` subroutine, which accepts `Cool` and `Numeric` arguments, as well as its method form (`Numeric.log2`)
- Allowed colon syntax on `$.foo` method, making `$.foo: 42` work as well as equivalent `self.foo: 42
- Add `RAKU_EXCEPTIONS_HANDLER` env variable
- Add `RAKUDO_HOME` env variable
