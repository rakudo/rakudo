# Announce: Rakudo compiler, Release #197 (2026.09)

On behalf of the Rakudo development team, I’m happy to announce the
September 2026 release of Rakudo #197. Rakudo is an implementation of
the Raku[^1] language.

The source tarball for this release is available from
<https://rakudo.org/files/rakudo>.
Precompiled archives will be available shortly.

The 2026.09 release marks a major step towards a Rakudo release with
language level 6.e.  It makes the RakuAST implementation of the Raku
grammar and actions the default.  This milestone
highlights the work of approximately 5000 commits since 2020.

Great care was taken for this migration to be as painless and unnoticeable
as possible, both from a feature **and** performance point of view.

In the unlikely event that a problem is found with this release, please report 
it (as always) via [github](https://github.com/rakudo/rakudo/issues).

This milestone is a key step in the roadmap to releasing Raku language level 6.e,
which will occur in a future release.
To test your code in advance, add `use v6.e.PREVIEW;` to your code, or
set the `RAKU_LANGUAGE_LEVEL` environment variable to "v6.e.PREVIEW".

New in 2026.09:

This release implements 6.c and 6.d versions of the Raku specification.
6.c version of the language is available if you use the `use v6.c`
version pragma, otherwise 6.d is the default.

Upcoming releases in 2026 will include new functionality that is not
part of 6.c or 6.d specifications, available with a lexically scoped
pragma. Our goal is to ensure that anything that is tested as part of
6.c and 6.d specifications will continue to work unchanged. There may
be incremental spec releases this year as well.
