# Announce: Rakudo compiler, Release #198 (2026.11)

On behalf of the Rakudo development team, I’m very happy to announce the
November 2026 release of Rakudo #198. Rakudo is an implementation of
the Raku[^1] language.

The source tarball for this release is available from
<https://rakudo.org/files/rakudo>.
Precompiled archives will be available shortly.

In addition to the many fixes and additions, the 2026.11 release of Rakudo *also* contains a security fix
in the module installation process that would technically allow executable scripts to be installed outside
of the repository prefix (See: [Security Advisory](https://github.com/rakudo/rakudo/security/advisories/GHSA-wr65-wcp9-gq83)).
None of the module distributions in the Raku ecosystem were found to take advantage of issue.
Any future attempt to use this attack vector will fail starting with this Rakudo release.

Thanks to Erik Johansen (@uniejo) for reporting and providing the initial remedy and testing and collaboration of the included solution.

This release implements 6.c and 6.d versions of the Raku specification.
6.c version of the language is available if you use the `use v6.c`
version pragma, otherwise 6.d is the default.

Upcoming releases in 2026 will include new functionality that is not
part of 6.c or 6.d specifications, available with a lexically scoped
pragma. Our goal is to ensure that anything that is tested as part of
6.c and 6.d specifications will continue to work unchanged. There may
be incremental spec releases this year as well.
